🤖 AI Interview Coach

AI Interview Coach is an interactive interview preparation platform that helps students practice different types of interview questions.

📌 Features

- 🐍 Python questions
- 🤖 Machine Learning questions
- 🗄️ SQL questions
- 🧠 HR / Aptitude questions
- ⏱️ Timed tests
- 📝 Multiple-choice questions
- 📊 Test results
- 🏠 Back to Home option

🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

🎯 Purpose

The project is designed to help students practice interview questions and improve their technical and aptitude skills.

🚀 Future Improvements

- AI-generated questions
- Different difficulty levels
- Performance tracking
- Personalized interview recommendations
