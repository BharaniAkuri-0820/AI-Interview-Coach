# 🤖 AI Interview Coach

A beginner-friendly Flask web application designed to help students practice interview questions and improve their preparation.

## 📌 Overview

AI Interview Coach provides a simple platform where users can choose an interview category, take a timed quiz, review their answers, and track their progress.

## ✨ Features

- 🐍 Python interview practice
- 🤖 Machine Learning questions
- 🗄️ SQL questions
- 🧠 HR / Aptitude questions
- ⏱️ Timed quizzes
- 📝 Multiple-choice questions
- 📊 Result and answer review
- 💾 Progress tracking using SQLite
- 🏠 Easy navigation back to Home

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
